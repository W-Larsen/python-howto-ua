# Сховище коду учнів (Google Таблиця)

Сторінка `#/globe` зберігає код учнів у вашій Google Таблиці через
Apps Script. Налаштовується один раз, приблизно 10 хвилин. Поки цього
не зроблено, сторінка працює, але код лишається тільки в браузері учня.

## 1. Таблиця і скрипт

1. Створіть нову Google Таблицю, наприклад «Touch The Globe — код учнів».
2. **Розширення → Apps Script**. Відкриється редактор з файлом `Code.gs`.
3. Зітріть усе, що там є, і вставте вміст файлу [`Code.gs`](Code.gs) з цієї папки.
   Натисніть 💾 (Зберегти).
4. Угорі виберіть функцію **`setup`** і натисніть **Run**. Google попросить
   дозвіл на доступ до таблиці: **Review permissions → ваш акаунт →
   Advanced → Go to … (unsafe) → Allow**. Це ваш власний скрипт, а
   попередження стандартне для всіх неперевірених скриптів.

У таблиці з'являться аркуші `code`, `history`, `classes`, `settings`.

## 2. Класи та ключ учителя

- **`classes`**: у стовпчику A, починаючи з 2-го рядка, коди класів, по
  одному в клітинці (наприклад `9A`, `9B`). Учень вводить цей код під час
  входу. Великі й малі літери не мають значення.
- **`settings`**, клітинка **B1**: ваш ключ учителя. Обов'язково замініть
  `змініть-мене` на свій: поки стоїть `змініть-мене`, сторінка вчителя не відкриється
  (цей ключ є в репозиторії, тож нічого не захищав би).

## 3. Опублікувати як веб-застосунок

1. У редакторі Apps Script: **Deploy → New deployment**.
2. ⚙️ **Select type → Web app**.
3. **Execute as: Me**, **Who has access: Anyone**.
4. **Deploy** → скопіюйте **Web app URL** (закінчується на `/exec`).

## 4. Вписати адресу на сайт

У файлі `js/globe-config.js`:

```js
window.GLOBE_CONFIG = {
  endpoint: "https://script.google.com/macros/s/…/exec"
};
```

Закомітьте й опублікуйте сайт. Готово: учні вводять ім'я та код класу, а
ви бачите їхній код на сторінці `#/globe-teacher` (або просто в аркуші `code`).

## Країни з аудіо учнів

На сторінці `#/globe-teacher`, у розділі **«Країни глобуса»**: **＋ Додати країну** → ID (`FR`), назви,
текст розповіді, mp3 учнів (до 5 МБ) → **Зберегти країну**. Ключ учителя береться з поля вгорі сторінки.

- Описи країн лягають в аркуш `countries`, а mp3 — у теку **«Touch The Globe — аудіо»** на вашому Google Drive.
- Нова країна одразу є в учнів (після оновлення сторінки): перевірка коду її знає, симулятор грає її запис.
- Країну з проєкту (наприклад `UA`) можна **замінити** своїм текстом чи записом; «Прибрати» повертає проєктну.
- **Після будь-якої зміни країн скачайте заново і «Скетч Arduino класу», і «SD-картку»**: номери треків
  розставляються за абеткою ID, тож нова країна зсуває номери інших.

Якщо скрипт у вас налаштований раніше, ніж з'явилися країни, його треба оновити (наступний розділ) і ще раз
запустити `setup`: Google попросить дозвіл на Google Drive — це для теки з mp3.

## Країни кнопок

На сторінці `#/globe-teacher`, у розділі **«Країни кнопок»**: оберіть для кожної кнопки країну (кнопка 1 — `UA`,
кнопка 2 — `AU`…) → **Зберегти кнопки**. Таблиця однакова для всіх учнів і лежить у клітинці `settings!B2`
(ID через кому: `UA,AU,JP`).

- Гра «Блискавка» і вікторина беруть правильну відповідь із цієї таблиці, тож **задачі 2 і 3 не залежать від задачі 1**.
- Учні бачать таблицю над редактором і ставлять у `task1.py` ту саму країну. Якщо поставили іншу, код працює,
  а «Перевірити» лише попереджає.
- Таблиця потрапляє в `settings.py` Python-проєкту (`BUTTON_COUNTRIES`) і в `student_code.h` скетча:
  **після зміни скачайте скетч і проєкт заново**.
- Поки таблиця порожня, ігри працюють як раніше: відповідь дає `on_button` із задачі 1.

Для цього скрипт треба оновити (наступний розділ): без нової версії `Code.gs` сайт просто працює без таблиці.

## Якщо змінили Code.gs

1. Вставте новий вміст `Code.gs` замість старого і збережіть (💾).
2. Виберіть функцію **`setup`** → **Run** (Выполнить). Якщо Google попросить нові дозволи — дозвольте.
3. **Deploy → Manage deployments** (Начать развертывание → Управление развертываниями) → ✏️ →
   **Version: New version** (Новая версия) → **Deploy**.

Адреса `/exec` лишається тією самою — на сайті нічого міняти не треба. Без кроку 3 сайт і далі говорить
зі старою версією скрипту.

## Що де лежить

| Аркуш | Що там |
|---|---|
| `code` | останній збережений код кожного учня з кожної задачі |
| `history` | кожне збереження окремим рядком: якщо учень усе стер, старий код є тут |
| `classes` | дозволені коди класів |
| `countries` | країни, які ви додали на сайті (mp3 — у теці «Touch The Globe — аудіо» на Drive) |
| `settings` | B1: ключ учителя; B2: країни кнопок — ID через кому («UA,AU,JP»), однакові для всіх учнів |

Ключ учителя бачить лише той, хто має доступ до таблиці. Учні без ключа
можуть завантажити тільки свій власний код: потрібно знати ім'я та код класу.
