# Сховище коду учнів (Google Таблиця)

Сторінка `#/globe` зберігає код учнів у вашій Google Таблиці через
Apps Script. Налаштовується один раз, приблизно 10 хвилин. Поки цього
не зроблено, сторінка працює, але код лишається тільки в браузері учня.

## 1. Таблиця і скрипт

1. Створіть нову Google Таблицю, наприклад «Touch The Globe — код учнів».
2. **Розширення → Apps Script**. Відкриється редактор з файлом `Code.gs`.
3. Зітріть усе, що там є, і вставте вміст файлу [`Code.gs`](Code.gs) з цієї папки.
   Натисніть 💾 (Зберегти).
4. Угорі виберіть функцію **`setup`** і натисніть **Run**. Google попросить
   дозвіл на доступ до таблиці: **Review permissions → ваш акаунт →
   Advanced → Go to … (unsafe) → Allow**. Це ваш власний скрипт, а
   попередження стандартне для всіх неперевірених скриптів.

У таблиці з'являться аркуші `code`, `history`, `classes`, `settings`.

## 2. Класи та ключ учителя

- **`classes`**: у стовпчику A, починаючи з 2-го рядка, коди класів, по
  одному в клітинці (наприклад `9A`, `9B`). Учень вводить цей код під час
  входу. Великі й малі літери не мають значення.
- **`settings`**, клітинка **B1**: ваш ключ учителя. Обов'язково замініть
  `змініть-мене` на свій. Без ключа сторінка вчителя не покаже код учнів.

## 3. Опублікувати як веб-застосунок

1. У редакторі Apps Script: **Deploy → New deployment**.
2. ⚙️ **Select type → Web app**.
3. **Execute as: Me**, **Who has access: Anyone**.
4. **Deploy** → скопіюйте **Web app URL** (закінчується на `/exec`).

## 4. Вписати адресу на сайт

У файлі `js/globe-config.js`:

```js
window.GLOBE_CONFIG = {
  endpoint: "https://script.google.com/macros/s/…/exec"
};
```

Закомітьте й опублікуйте сайт. Готово: учні вводять ім'я та код класу, а
ви бачите їхній код на сторінці `#/globe-teacher` (або просто в аркуші `code`).

## Якщо змінили Code.gs

**Deploy → Manage deployments → ✏️ → Version: New version → Deploy**.
Адреса `/exec` лишається тією самою.

## Що де лежить

| Аркуш | Що там |
|---|---|
| `code` | останній збережений код кожного учня з кожної задачі |
| `history` | кожне збереження окремим рядком: якщо учень усе стер, старий код є тут |
| `classes` | дозволені коди класів |
| `settings` | B1: ключ учителя |

Ключ учителя бачить лише той, хто має доступ до таблиці. Учні без ключа
можуть завантажити тільки свій власний код: потрібно знати ім'я та код класу.
