# Тема 06 «Файли» — дизайн-документ

Дата: 2026-10-06
Статус: затверджено, план — `docs/superpowers/plans/2026-10-06-topic-file-io.md`
Гілка: `feature/topic-file-io`

## 1. Мета

Нова тема посібника — **«Файли»** (`#/files`, номер **06**), одразу після
«Колекцій». Учень має зрозуміти, як програма зберігає дані між запусками:
відкрити файл, прочитати його, записати в нього, не загубити кирилицю й
розібрати CSV.

Основа змісту — CS50P, лекція 6 (File I/O) і Automate the Boring Stuff, 3-тє
видання, розділ 10 (Reading and Writing Files). Обидва джерела переказуємо
своїми словами, з українськими прикладами, а не перекладаємо.

Критерій успіху: тема виглядає й поводиться як решта тем (покрокові віджети,
номери розділів, «Перевір себе», шпаргалка, позначка «пройдено»), і кожен
кадр кожного віджета збігається з тим, що робить справжній Python.

## 2. Межі

**Робимо:** текстові файли (`open`, режими `r`/`w`/`a`, `with`, читання й
запис), `FileNotFoundError`, коротко про шляхи й `pathlib`, Advanced-розділ
про CSV (`csv.reader`, `DictReader`, `DictWriter`).

**Не робимо:** живий Python (Pyodide) на сторінці теми, окрему практику із
завданнями й тестами, бінарні файли й зображення (PIL), `shelve`, `glob`,
створення папок, `os.path`. Окрема практика, якщо знадобиться, — це окремий
підпроєкт зі своїм spec.

## 3. Головна ідея візуалізації: «блокнот із невидимими символами»

У кожному віджеті під кодом (`extra` у `createPlayer`) лежить **блокнот** —
вигляд відкритого файлу:

- шапка: ім'я файлу й бейдж стану — `закрито` або `відкрито: r` / `w` / `a`;
- рядки з номерами, як у текстовому редакторі;
- на кожному `\n` — блідий символ `↵`, щоб було видно, що кінець рядка — це
  теж символ, який потрапляє в змінну;
- **каретка** — поточна позиція у файлі; під час читання вона йде по тексту,
  у режимі `a` стрибає в кінець, у режимі `w` файл спершу очищується;
- стани підсвітки фрагментів: щойно прочитане (`read`), щойно записане
  (`new`), стерте (`gone`);
- порожній файл показується написом «файл порожній» з кареткою на початку.

Для CSV поруч із блокнотом — **таблиця**, яка заповнюється, коли `csv.reader`
чи `DictReader` розбирає черговий рядок.

## 4. Зміст сторінки

Структура — як у «Словниках»: hero, основні розділи, Advanced, «Перевір
себе», «Шпаргалка». Перемикачі віджетів — наявний `modeCfg`.

Приклади даних: `names.txt` з іменами учнів, `students.csv` зі стовпцями
`name,class,grade` (ім'я, клас, оцінка).

| # | Розділ | Віджет | Що показує |
|---|---|---|---|
| hero | — | `names.txt` наповнюється рядок за рядком, програма завершується | змінні зникли, файл лишився |
| 6.1 | Навіщо файли | — | змінні живуть, поки працює програма; файл — після неї |
| 6.2 | `open` і режими | перемикач **r / w / a** | та сама програма з `f.write("Ніна\n")`: `w` стирає файл і пише заново, `a` дописує в кінець, `r` падає з `io.UnsupportedOperation: not writable` |
| 6.3 | `with` | перемикач **with / open…close** | помилка посеред роботи з файлом: з `with` файл закрився попри помилку, без нього лишився відкритим (бейдж у шапці блокнота) |
| 6.4 | Читання | перемикач **read() / for line in f / for + rstrip() / readlines()** | каретка йде по тексту; у змінних видно `"Оля\n"`; без `rstrip` у виводі з'являються порожні рядки; другий `read()` повертає `""` |

| 6.6 | Коли файлу немає | перемикачі **файл є / немає** і **без try / з try** | `FileNotFoundError`, потім той самий код у `try/except`; блокнот у стані «немає»; посилання на тему «Функції» |
| 6.7 | Де шукається файл | перемикач **звідки запущено** | дерево папок із позначкою «тут запущено»: `open("names.txt")` знаходить файл або ні. Абсолютний шлях, `Path("data") / "names.txt"`, `.exists()`, `read_text()` / `write_text()` — на цьому `pathlib` закінчується |

| 6.9 | Чому не просто `split(",")` | перемикач **split(",") / csv.reader** | рядок `"Іваненко, Оля",9-А,11`: `split` дає 4 шматки, `csv.reader` — правильні 3 |

| 6.11 | Запис CSV | плеєр | `DictWriter`, `writeheader`, `writerow`; блокнот наповнюється |

Номери розділів (`6.1`…) ставить `Book.numberHeads` автоматично — у таблиці
вони лише для орієнтації.

**Виноски** (`.callout`):

- `encoding="utf-8"` — без нього на Windows кирилиця у файлі ламається;
  у прикладах сторінки він стоїть у кожному `open`;
- `"w"` стирає файл без жодного попередження;
- `print(..., file=f)` — альтернатива `f.write`, яка сама додає `\n`;
- `newline=""` при записі CSV — модуль `csv` сам пише `\r\n`, і без
  `newline=""` Windows додасть ще один `\r`: в Excel між рядками з'являться
  порожні.

**«Перевір себе»** — 5–6 задач у форматі наявних `.task` / `.answer`,
наприклад: що буде у файлі після двох запусків програми з режимом `"a"`; чому
у виводі порожні рядки; що поверне другий `read()`; скільки частин дасть
`split(",")` на рядку з комою в лапках; що станеться з `open(..., "r")`, якщо
файлу немає.

**«Шпаргалка»** — `table.cheat`: `open` і режими, `with`, `read`,
`for line in f`, `readlines`, `rstrip`, `write`, `print(file=f)`,
`encoding`, `FileNotFoundError`, `Path`, `.exists()`, `read_text`,
`csv.reader`, `DictReader`, `DictWriter`, `newline=""`.

**Картка на головній** — у вкладці «Теми», `data-viz="files"`: SVG-блокнот,
у якому по черзі з'являються рядки й біжить каретка.

### Контракт `notepad(file)`

Вхід — об'єкт:

- `name` — ім'я файлу (`"names.txt"`);
- `mode` — `null` (закрито) або `"r"` / `"w"` / `"a"`;
- `text` — увесь вміст файлу як рядок, з `\n`;
- `pos` — позиція каретки, індекс символу в `text`, або `null` (без каретки);
- `marks` — необов'язковий список `{from, to, cls}` з `cls` ∈ `read`, `new`, `gone`;
- `missing` — `true`, якщо файлу немає зовсім: у шапці «немає», у тілі —
  «такого файлу немає», рядків немає.

Вихід — HTML-рядок. Увесь текст екранується. Кожен `\n` рендериться як
`↵` у кінці свого рядка. Порожній `text` — напис «файл порожній».
Каретка в самому кінці файлу, що закінчується `\n`, стоїть на новому
порожньому рядку; цей рядок показується лише тоді, коли в ньому каретка.

### Контракт `csvTable(head, rows, cur)`

`head` — масив назв стовпців, `rows` — масив масивів клітинок, `cur` —
необов'язковий індекс рядка в `rows`, який щойно додано (підсвічується).
Вихід — HTML-рядок, текст екранується. Порожній `rows` — лише шапка.

## 6. Помилки в плеєрі

Винятки (`io.UnsupportedOperation`, `FileNotFoundError`) показуються так
само, як у темі «Функції»: червоний рядок у виводі й кадр `kind:"end"`.

## 7. Перевірка

- **Юніт-тести** (`tests/checks.html`): `notepad` ставить `↵` на кожен `\n`,
  каретку — на правильну позицію, екранує HTML, показує порожній файл;
  `csvTable` будує правильну кількість рядків і клітинок і екранує текст.
- **CSS-токени**: `python -m unittest tests/test_css_tokens.py -v` з новим
  `"files"` у `TOPICS` — контраст AA в обох темах.
- **Звірка з реальним Python**: кадри плеєрів пишуться вручну, тож кожен
  фрагмент коду з віджетів і задач «Перевір себе» проганяє справжнім
  `python` у тимчасовій папці скрипт
  `docs/superpowers/plans/2026-10-06-topic-file-io/snippets_check.py`; вивід
  і вміст файлу мають збігатися з тим, що показує віджет і відповідь.
- **Браузер** (`.claude/launch.json`, конфігурація `site-win`): маршрут
  `#/files`, меню й зміст, картка й мініатюра на головній, кожен віджет від
  першого до останнього кадру з кожним перемикачем, світла й темна тема,
  ширина телефона без горизонтальної прокрутки, консоль без помилок.
